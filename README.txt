4-Week High-Protein Vegetarian Budget Meal Planner - Interactive Site

Open index.html in a browser to use the site.

No personal names, email addresses, or private details are included.
Prices are planning estimates from the cookbook project and may vary by store, promotion and date.

Sections included:
- Overview dashboard
- Four Tuesday-Monday meal plans
- Carry-forward-aware shopping lists
- Monday and Thursday batch-cooking guides
- Searchable recipe cards

To publish online, upload all files in this folder to a static site host, or upload the ZIP package where your site builder accepts static web files.
